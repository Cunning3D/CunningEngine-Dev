# 程序化建筑生成系统 - 简化模式

## 简介

简化模式是程序化建筑生成系统的一种轻量级替代方案，专为以下场景设计：

1. 远距离视角中的建筑模型
2. 性能要求较高的场景（如VR、移动平台）
3. 需要快速生成大量建筑的情况
4. 与Houdini HDA结合使用的高级建筑生成工作流

在简化模式下，建筑的门窗和楼层都使用单个面片来表示，大幅减少了多边形数量和渲染压力。

## 功能

- **轻量级网格**：使用最少的多边形数量生成建筑外观
- **简化窗户**：使用面片+透明材质表示窗户，保留发光效果
- **简化楼层**：可选择性地生成楼层分隔面片
- **Houdini集成**：支持与Houdini HDA资源集成以实现高级生成效果
- **快速编辑**：便于快速调整建筑规模和结构

## 使用方法

### 开启简化模式

1. 选择建筑物体
2. 在Inspector面板中，找到"简化模式：已关闭"按钮
3. 点击该按钮开启简化模式
4. 在弹出的对话框中选择是否立即重新生成建筑

### 简化模式参数

- **生成简化窗户**：是否生成窗户面片
- **生成简化楼层**：是否生成楼层面片
- **窗户密度**：控制窗户的数量和密度
- **楼层高度**：控制每层的高度

### Houdini HDA集成

如果你拥有Houdini Engine插件，可以：

1. 将HDA资源拖放到"Houdini HDA资源"字段
2. 通过HDA资产生成更复杂的简化建筑模型
3. 利用Houdini的程序化能力创建具有变化性的简化建筑

## 性能对比

| 模式 | 多边形数量 | 渲染成本 | 适用场景 |
|-----|----------|---------|--------|
| 标准模式 | 高 | 高 | 近距离视角、静态场景、特写镜头 |
| 简化模式 | 低 | 低 | 远距离视角、大场景、移动平台 |

## 注意事项

1. 简化模式下生成的模型具有不同的光照和阴影特性
2. 简化模式可能不适合非常近距离的观察
3. 窗户发光效果在简化模式下仍然可用，但视觉效果有所不同
4. 使用Houdini HDA资源需要安装Houdini Engine插件

## 技术说明

简化模式的实现主要依赖于以下技术：

- 面片几何体生成
- 透明材质窗户效果
- 材质属性块（MaterialPropertyBlock）实现高效发光效果
- 三角形扇形网格生成楼层
- Houdini Engine API集成（如可用）
